# NagarConnect v2

NagarConnect is a municipal grievance management platform for reporting and tracking civic issues, with role-based dashboards for users, ward admins, and admins.

## Live Demo

Frontend: https://nagar-connect-v2.vercel.app/

## Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express
- Auth/DB: Supabase

## Setup Flow (Primary)

- Backend setup and run: [backend/README.md](backend/README.md)
- Frontend setup and run: [frontend/README.md](frontend/README.md)

## Repository Notes

- Deployment: `DEPLOYMENT.md`
- Supabase auth migration: `SUPABASE_AUTH_MIGRATION.md`
- Render config: `render.yaml`

## Core Features

- User authentication (including Supabase auth flow)
- Complaint registration and status tracking
- Discussion forum for community interaction
- Admin dashboard and ward admin dashboard
